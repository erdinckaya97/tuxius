★ Star on GitHub Download 

      

    


    

      
Everything you need. Nothing you don't.

      
A single small binary that drives the OpenSSH client already on your machine.

      

        
❯_
One command
Type tuxius and get a searchable list of your servers. Arrow keys, Enter, done.

        
⚿
Password once, then never
Tuxius uses your root password once to install an SSH key. The password is never stored.

        
⌕
Fuzzy search
Start typing a name or an IP to filter. Most recently used servers float to the top.

        
→
Direct connect
tuxius web jumps straight in, tuxius web -- df -h runs a command.

        
⚑
Speaks your language
English, Türkçe and Русский — picked from your system, or set with tuxius lang.

        
⚿
Bring your own keys
Import the SSH keys you already use or generate new ones. Removing a server can also revoke its key.

      

    


    

      
Up and running in a minute

      
Works on Linux and macOS, Intel and ARM.

      

        
curl … | sh
Install with the one-liner above, or cargo install --git.

        
tuxius add
Name it, enter the host and root password. Tuxius sets up a key for you.

        
tuxius
Pick a server from the list. That's it — you're connected.

      

      


      

        
tuxiusOpen the server picker

        
tuxius <name>Connect directly

        
tuxius <name> -- <cmd>Run a command on the server

        
tuxius addSave a new server

        
tuxius listList saved servers

        
tuxius edit / tuxius rmChange or remove a server

        
tuxius keyImport, generate, show or delete SSH keys

        
tuxius lang ruChange the interface language (en, tr, ru)
